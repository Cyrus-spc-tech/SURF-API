# SURF-API
A collection of API projects, experiments, and utilities built in Python and other languages.

## Overview

This repository is designed to serve as a playground and reference for:

- RESTful API development
- FastAPI / Flask microservices
- API consumption and integration
- Authentication (OAuth, API keys, tokens)
- Real-world use cases (weather, finance, chatbots, etc.)
- Automation and data exchange using APIs
